## 1. 金钱

- 单位：文。开局身上 120 文（D-079）。
- 来源：城市衙门的差事（除害、送信）、跑商、主线奖励。
- 去处（D-105）：
  - 武馆学基础武功（几十文）、铁匠铺的普通兵器（几十到一百多文）：前期。
  - **上等兵器**：精钢剑 / 刀 / 枪（+20%，临安 600 文、襄阳 560 文），百炼剑 / 刀 / 枪（+28%，只有襄阳打，2400 文）。门派绝学任务的兵器（+40% 以上）仍然更好，所以上等兵器是"没做绝学任务之前"的升级。
  - **武馆陪练**：200 文换 30 潜能、1000 文换 120 潜能，两档共用每天一次。钱多了可以换成武功进度，但每天只能一次，不会压过打怪和差事。
  - **镖师**（D-104、D-122）：车马行雇镖师护送下一趟，每辆车一个，每人 50 文加这辆车货值的 8%。
  - **添车**（D-122）：车马行加一辆马车，依次 2000 / 5000 / 10000 / 30000 文，最多 5 辆。
- **钱庄**（各城都有）：`存 100` / `取 全部` / `存款`。各地通兑，**没有利息**，存着的钱不会被劫走。

## 3. 跑商

- 市集 `行情` 查看当天价格，`买 丝绸 5`、`卖 丝绸 全部`。
- 每辆马车装 **100 件**货（D-077）。起步一辆，车马行可以添车，最多 5 辆 500 件（D-122）。货物在马车上，走路时不用管。
- **存货**（D-123）：每种货有存货上限，特产 500 件，外地货 100 件。被买走后每天补回来，先快后慢：第二天补回一半，约 7 天补满（缺口每天剩 52%）。

**大方针（用户定，D-077）：本地特产便宜，本地没有的货贵。** 跑商就是把特产运到不产它的地方卖，再收当地的特产运回来。价格有小幅波动，但这个方针不变；**跑商唯一的风险是路上的劫匪**。

- **每个市集都显示全部货物的价格**（D-076）。任何货都能卖；外地货也能买，但买价是行情价的 1.8 倍，倒卖怎么都亏，只适合凑门派的材料差事（D-123、D-125）。
- **特产**：城市 `goods` 里列出的货，倍率 0.6~0.7。
- **外地货**：倍率 = 1.15 + 0.06 × 离最近产地的路程（天），最高 1.8。离产地越远越贵。
- 价格 = 基准价 × 倍率 × 当日波动（±10%，同一天同一城市固定，刷新不变）。卖价是行情价的九成。
- 这样定的结果：特产运到任何一个不产它的城市都赚钱，最差的一天也有三成左右；远途（十几天）平均能赚到一倍半以上。路越远利越厚，被劫的概率也越高（§4）。

| 城市 | 特产 |
|---|---|
| 临安 | 丝绸、茶叶 |
| 嘉兴 | 丝绸、盐 |
| 襄阳 | 铁器、药材 |
| 洛阳 | 瓷器、铁器 |
| 长安 | 皮货、盐 |
| 成都 | 蜀锦、药材、茶叶 |

- 典型商路：临安茶叶 ⇄ 嘉兴盐（一天路程，利薄风险小）；洛阳瓷器 ⇄ 长安皮货（四天）；嘉兴丝绸、成都蜀锦、长安皮货跑长途（十几天，利最厚，劫匪也最多）。
- 校验脚本检查：城市 `goods` 只能列特产（倍率 ≤ 0.8），每种货至少有一个产地。

## 4. 劫道

每次坐车都会判定是否被劫：

```
被劫概率 = min(65%, 3% × 天数 + 50% × 货值 / (货值 + 5000))   # 马车扩到 100 件后，货值尺度从 2000 调到 5000（D-077）
劫匪人数 = 上路的车数 = ceil(车上件数 / 100)，空车也算一辆（D-122）
单个劫匪 = 主角一个人的战力 × 难度系数 × 单个强度
  难度系数 = 1 + 0.2 × min(1, √(总值 / 50000))，总值 = 货值 + 身上现钱
  单个强度 = 1 − 0.1 × (车数 − 1)；有 10% × 车数的概率折扣改成 0 ~ 0.4 之间随机（一到五辆车总战力约 1 / 1.8 / 2.4 / 2.8 / 3 倍主角）
```

- 货值按基准价计算。空车走短途也有一点被劫的可能。
- **劫匪的武功等级跟着主角走，每个劫匪单独按"主角一个人打它"放缩**（D-115、D-122），队友、镖师、客人都不会让劫匪变强。所以几辆车就是几倍的主角：一辆车自己打得过，两辆以上就得雇镖师或者组队。
- 货物和现钱越值钱，难度系数越高（最多 1.2）。把钱存进钱庄可以降低一点。
- 不能逃跑。
- **打赢**：照常到达，获得潜能和实战经验。
- **打输**：货物全部丢失，身上现钱减半，气血剩三成，马车照常把你送到目的地。

### 镖师（D-104、D-122）

- 车上有货时，车马行的目的地列表最前面多出"雇 1 个 / 2 个……镖师护送下一趟"，最多雇上路车数个。每个镖师 `50 + 每辆车平均货值 × 8%` 文，雇满合计约货值的 8%。雇了之后各目的地后面标"（N 个镖师随行）"，只管下一趟。
- 雇了（不论几个）被劫的机会乘 0.4。真遇上了，镖师作为 NPC 队友（`escort: true` 的敌人块，`world.ally.biaoshi`）和你并肩作战，也按主角一个人的战力放缩，和一个劫匪差不多强。镖师倒下不算输。

### 奇遇（D-114）

- 没遇上劫道时，20% 碰上一段路上的小故事（`content/world/qiyu-tales.md`，40 个，看完一轮才重复）。
- 选对了：50~150 文、潜能 20~60；8% 根骨/身法/悟性随机一项 +1；3% 送一本秘籍（`content/world/qiyu.md` 的六门武学，别处拿不到）。选错了无事发生。
- 组队时照样触发（D-126）：队长选，选对了每个客人也各得一份钱和潜能，各有机会长属性；秘籍只给队长。

## 5. 城市差事

各城衙门的公差发放可重复的差事：

各城差事**每天各做一次**，第二天刷新（D-054）。除害、缉拿、查访和 `content/world/jobs.md` 的五件（贴告示、钱庄查假银票、市集巡夜、客栈醉汉、车马行拐子）组成差事池，**每天随机抽 3 件**（D-124）；送信不参加抽选：

| 差事 | 内容 | 奖励 |
|---|---|---|
| 除害 | 车马行一带的本地匪徒（两人一组） | 80 文 + 潜能 + 实战经验 |
| 缉拿飞贼 | 市集里的飞贼（用匕首，身法快） | 120 文 + 潜能 + 实战经验 |
| 查访客栈 | 走到本城客栈即完成 | 40 文 + 15 潜能 |
| 张贴告示 / 钱庄查访 / 市集巡夜 | 走到本城中心 / 钱庄 / 市集即完成（D-124） | 40~50 文 + 15 潜能 |
| 客栈醉汉 / 车马行拐子 | 两人一组，按玩家战力浮动（D-124） | 80 / 110 文 + 潜能 + 实战经验 |
| 送信 | 送到相邻城市的衙门（每条路线每天一次） | 30 + 天数 × 15 文 + 10 潜能 |

各城匪徒强弱不同：临安、嘉兴面向刚出道的玩家，襄阳面向入门弟子，洛阳、长安、成都面向二袋左右的玩家。送信顺路还可以跑一趟货。
