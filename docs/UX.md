# 交互与界面设计（v0.2）

> 状态：**已定稿 v0.2**（可随实现调整）。优先级 P0 = 第一版就要，P1 = 战斗/联机做完后，P2 = 锦上添花。
> 相关决策：[DEVLOG.md](DEVLOG.md) D-018 ~ D-020。

## 1. 出发点

古早 MUD 跑在 telnet 终端里：只能输入命令、只能显示文字和几种颜色。后来的客户端（zMUD 等）加了按钮和小地图，但本质仍是"命令行 + 文字流"。

网页让我们可以做到：**文字依然是主角，但所有文字都可以点。**

几条原则：

1. **文字优先**：不做图形化地图行走、不做立绘，氛围靠文字和排版。美术成本低，这也是 MUD 的魅力所在。
2. **点击与命令并存**：手机和新手用点击；老玩家用命令行和快捷键，两种方式都能完成所有操作。
3. **界面只把文字里已有的信息整理出来**，不提供文字里没有的信息。例如战斗界面不会直接标出"敌人这回合出刚招"，否则读预兆就没意义了。
4. **手机能玩**：大量文字适合在手机上躺着看。

### 手机端

- 正文全屏，底部是输入框和一行情境按钮（出口、可交互的人）。
- 侧栏内容收进底部抽屉：地图、状态、笔记、武学。
- 气血、内力常驻在顶部，做成细条。

## 3. 探索

### 3.1 文字里的一切都能点（P0）

链接（人名、物品、出口、地名、武功名）**始终用不同颜色显示**，与普通正文区分开（D-022）。三种操作：

| 操作 | 效果 |
|---|---|
| **左键单击** | 执行默认动作：出口 → 走过去；人 → 交谈；物品 → 查看 |
| **鼠标悬停** | 弹出信息卡：简介、"你对他的了解"（取自江湖笔记），以及全部可用动作（查看 / 交谈 / 切磋 / 给予…） |
| **右键单击** | **固定**信息卡：卡片不再随鼠标移开而消失，可以拖动，带关闭按钮 |

- 信息卡里的文字也可以带链接。固定之后，鼠标移进卡片，悬停卡片里的链接会再弹出下一层卡片。这样可以顺着"人物 → 门派 → 武功"一路查下去。
- 最多同时固定 3 张，再固定一张时关闭最早的那张。按 Esc 关闭全部。
- 右键只在链接上拦截，其他地方仍是浏览器原生菜单。
- **手机**：轻点 = 悬停（弹出信息卡），长按 = 固定，信息卡里的动作按钮负责执行。
- 内容文件里用 `[[显示名|id]]` 标记，如 `墙根下蜷着一个[[老乞丐|linan.beggar]]。`。对本房间在场的人和地上的物品，解析器会自动加链接，不必手写。

### 3.2 命令行增强（P0）

- **Tab 补全**：方向、在场人名、背包物品、武功名。
- **拼音首字母**：`talk lqg` → 老乞丐。中文输入法切来切去很烦，这条对命令行玩家很重要。
- 历史记录（已有），以及别名：`alias k 修炼 降龙十八掌`。
- 快捷键：方向键或小键盘移动（8=北、2=南…），数字键选择对话选项和招式。

### 3.3 自动小地图（P1）

- 从房间出口自动生成，**只显示去过的房间**（战争迷雾）。
- 点击地图上去过的房间可以**自动寻路**走过去。中途遇到剧情或战斗就停下。
- ✅ 位置**按出口方向自动推算**，不写坐标（D-021）。遇到冲突（两个房间推算到同一格）时自动错开；每个区域单独成图，跨区域出口在地图边缘显示为箭头。
- ✅ 已实现（D-034）：**常驻右侧，可以收起**（窄屏默认收起，点状态栏的"地图"按钮弹出）。区域按房间 id 前缀划分。与去过的房间相邻、但没去过的房间显示为虚线"？"。

### 3.4 江湖笔记（P1）

自动记录玩家在剧情中获得的**线索**。对"剧情即攻略"（D-015）很关键：

- **人物**：见过的人、他们说过的关键话。
- **传闻**：说书先生、告示、路人闲谈里的情报。
- **武学见闻**：敌人的路数。打过一次以后，记下"黑衣人：气血过半后只出巧招"。
- **典籍**：已获得的秘籍，以及各武功的等级上限。

内容中用效果 `!note:xxx` 写入笔记。笔记存进存档。

### 3.5 叙事节奏（P1）

- ✅ **只有标记为重场戏的段落**才逐段出现（D-023）：点一下或按空格出下一段。日常探索文字照常一次显示。内容中用 `=== scene: id` 块，或在对话块属性里写 `pace: slow` 来标记。
- 章节开始时显示一个章节标题页（大字、书法字体、留白）。
- 可选的打字机效果，默认关闭。爱读文字的人嫌它慢。
- **回顾**：正文区可以往回翻，可以搜索。也可以按章节回看已读剧情。

## 4. 对话（P0）

- 对话期间正文下方出现**对话框**：说话人名字单独一行，选项是按钮，可以用数字键选。
- 每个选项前标出它的条件来源，比如带"〔给出 铜钱〕"的选项会消耗物品，让玩家知道代价。
- 联机时：房主看到客人的建议以小标签挂在选项旁边（"阿青 → 2"），点一下即采纳。

## 5. 战斗（P0）

要做到两件事：**帮玩家读预兆**，以及**让队友能配合**。

```
┌─────────────────────────────────────────────────────────────┐
│ 第 3 回合                                     ⏳ ████░░ 12s │
│                                                             │
│ 黑衣人  气血 ██████░░░░ 受创不轻                            │
│ 「黑衣人深吸一口气，双掌缓缓提至胸前，衣袖无风自鼓……」      │
│   ⚠ 你察觉他的气息与架势并不相合……   ← 只有看破者能看到    │
│                                                             │
│ 队友  阿青 ✓ 已出招：缠丝手（守）→ 护你                     │
│       老王 … 思考中                                         │
│                                                             │
│ ┌刚────────┐ ┌巧────────┐ ┌守────────┐ ┌────────┐          │
│ │亢龙有悔  │ │穿花拂柳  │ │揽雀尾    │ │ 调息   │          │
│ │降龙十八掌│ │落英神剑掌│ │太极拳    │ │+43 内力│          │
│ │耗 40     │ │耗 15 点穴│ │耗 8 护法 │ │        │          │
│ └──────────┘ └──────────┘ └──────────┘ └────────┘          │
│  ★ 与阿青可合击「双燕穿林」                                 │
│ 内力 █████░░░ 180/436                                       │
└─────────────────────────────────────────────────────────────┘
```

- **招式卡片按势配色**：刚＝赭红，巧＝青，守＝金。玩家一眼就能看出自己有哪些势可选。
- **预兆单独放在显眼处**。上一回合的预兆和敌人实际出的招也保留在旁边，方便玩家学习对照。
- **队友的选择实时可见**（P0，多人的关键）：阿青选完，你马上看到"缠丝手→护你"，于是你知道该出巧招触发合击。
- **合击提示**：当队友已选的招式与你的某张卡片能构成合击时，该卡片发光并提示合击名。
  - 前提是你**已经学会**这个合击。没学会的合击不提示，靠自己发现，发现后写入江湖笔记。
- **结算动画**：结算文字逐行出现（约 0.4 秒一行），伤害数字从敌人气血条上跳出。可以点击跳过。
- **克制提示**：结算时用小标签标出"破防""落空""抢攻"，让玩家学会规则。
- 内力不够的卡片变灰。

## 6. 联机（P1）

- **队伍栏**：成员、气血、在线状态、延迟。
- **聊天**：独立的一栏，不混进正文。正文里只显示 `[队] 阿青：先打左边那个`。
- **建议**：客人点击任何出口、人名、选项时，弹出的菜单变成"建议房主……"。房主那边以可点击的小标签显示。
- **开队流程**：旅店里点"联机" → "开设队伍" → 显示暗号，附带"复制邀请"按钮，复制出的文字可以直接贴进聊天软件。

## 7. 存档与平台（P1）

- **PWA**：可以"安装到桌面/主屏幕"，离线也能玩（GitHub Pages 支持）。
  - 重要附加价值：调用 `navigator.storage.persist()` 请求**持久存储**，降低浏览器清理 localStorage 的风险（D-001 中提到的 Safari 7 天问题）。
- **自动备份**：保留最近 5 个自动存档快照，玩家可以回退。比如误选了剧情选项，或导入错了存档。
- **二维码转移**：导出时同时显示二维码，手机扫码即可导入，省去传文件。存档大了扫不了时，自动退回到文件方式。
- **导出提醒**：每过一段游戏时间（或每章结束）提示一次"要不要导出备份"。

## 8. 氛围（P2）

- **昼夜与天气**：顶部显示时辰，配色随之变化（黄昏偏暖、夜里偏暗）。剧情可以依赖时辰，比如"天黑以后去断桥"。
- **字体**：正文宋体或楷体，标题用书法字体（Google Fonts 有可用的中文书法字体）。
- 背景：淡淡的宣纸纹理，夜间模式下是墨色。
- 环境音：雨声、市集，默认关闭。
- 设置：字号、行距、繁简转换、关闭动画、关闭伤害数字。

## 9. 已定

2. 链接颜色区分，悬停弹信息卡，右键固定（D-022）。
3. 逐段出现只用于重场戏（D-023）。
4. 探索界面用原生 JS；做战斗界面时视情况引入 Preact + htm（D-020）。
