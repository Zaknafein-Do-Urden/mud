# 武学威力与剧情进度（D-068）

## 1. 要解决的问题

剧情里会传授武功秘籍。如果早期就拿到最终的强力武学，后面的武学就都没用了，成长也就断了。

用户定的规则：

> **必须要能打过战斗力 100 的敌人，才能获得威力大于 100 的武学。**

为此要有一把尺子，同时量"武学有多强"和"敌人有多强"，两边的数字可以直接比较。本文档定义这把尺子、规则、检查工具，并记录每一次剧情授予武学的安排。

## 2. 尺子：攻击值

战斗的伤害公式（COMBAT.md §5）：

```
攻击值 = 招式威力 × (1 + 外功等级 × 2%) × 内功加成
伤害   = 攻击值 × 克制倍率 × 目标护体 × 随机(0.9 ~ 1.1)
```

"攻击值"就是一个人出手有多重。威力和战斗力都用它来量。

### 2.1 武学威力（WP）

一门武学**练到某个等级**时的威力：

```
外功：WP(等级) = 已领悟招式中最强一招的 招式威力 × 效果系数 × (1 + 等级 × 2%)
内功、轻功：WP(等级) = 25 × (1 + 等级 × 2%)
```

- 内功加成按 1 计（只量武学本身）。辅助招式不算。
- **效果系数**：招式每带一个控制类效果（内伤、点穴、破绽、缴械）或群攻 +10%，每个内力类效果（吸内、化内）+5%。
- 内功、轻功没有招式，按"标准招式"折算。标准招式威力取 25，约等于门派入门招式（莲花掌第一招 24、罗汉拳第一招 22）。这样内功、轻功的上限和外功放在同一把尺子上比较。
- **剧情武学的威力，按授予后的上限等级计**。例如越女剑法上限 40，就按 40 级算：最强一招「回眸」威力 30、带点穴，30 × 1.1 × 1.8 ≈ 59。

### 2.2 敌人战斗力（CP）

```
CP(敌人) = 它最强一门外功在它的等级下的 WP × 它的内功加成（1 + 内功等级 × 1%）
CP(战斗) = 这场战斗里最强的那个敌人
```

例：射雕第四章的段天德，五虎断门刀 24 级、养气诀 22 级 → 战斗力 67。

## 3. 规则

1. **剧情授予的武学**（对话或使用物品里的 `learn:`、`cap:` 效果）：授予后的威力 **不能超过** 本主线到这一章为止（含本章）**必须打赢的战斗**里最强的战斗力。
   - 写了 `lose:` 的剧情战（允许打输）不计入：玩家不一定赢过它。
   - 同一章里的授予，按"本章的战斗都已打过"计算，所以**授予要放在本章战斗之后**（章节结尾）。
2. **秘籍先给低上限，随剧情提高**：一门武学的上限由 `cap` 属性（初始）和剧情里的 `cap:武学:等级` 效果（提高）决定。每提高一次，都要重新满足规则 1。
   - 例：杨家枪法第二章只给 10 级（威力 25），第五章提到 30 级（威力 42），日后杨铁心出场再往上提。
3. **文件顺序就是剧情顺序**：检查按 `index.json` 里本主线文件的顺序累计战斗力。支线文件要排在它实际能触发的位置（如重阳宫信物支线排在第四章之后，并且用 `if: flag:shediao.ch4_done` 保证真的要第四章之后才能用）。
4. **门派武学（包括门派绝学任务的奖励，D-085）不受此规则约束**：门派武学走阶位（阶位上限 40/70/100/140/180，晋阶要过考核），本身就是一条成长线。门派镇派绝学的威力远高于剧情武学，这是有意的：剧情武学是补充，不取代拜师。
5. **武馆基础武功**上限 50，任何人花钱就能学，作为基准线，也不受此规则约束。

## 4. 检查工具

- `node tools/power.mjs`：打印所有武学在各等级的威力、所有剧情战斗的战斗力，以及每一次剧情授予是否符合规则。
- `node tools/validate.mjs`：违反规则 1 时**报错**，内容不能提交。
- 公式在 `src/power.js`，两个工具共用。改公式只改这一个地方。

## 7. 写剧情时的检查清单

1. 先想好这一章最强的必胜敌人，用 `node tools/power.mjs` 看它的战斗力。
2. 要授予的武学，算它在授予后上限下的威力（同一个工具里有各等级的威力表）。
3. 威力超了，就降低授予时的上限，把剩下的留给后面的章节用 `cap:` 提高；或者把敌人调强（同时用 `node tools/balance.mjs` 确认胜率仍符合 D-051）。
4. 授予写在本章战斗之后、锁定的对话里（D-067），用 `do:` 给。
5. 跑 `node tools/validate.mjs`。

## 10. 拳掌与兵器（D-119）

用户规定：

> 用兵器的功法才能吃兵器的加成；掌法拳法基础伤害可以高一些，但不能享受兵器加成。
> 高级兵器（约 80 分）能买，但很贵；顶级兵器（90～100 分）只能来自剧情或任务奖励。
> 兵器武功配高级兵器，应该和拳掌武功战力差不多。

**兵器分档**：

| 档 | 加成 | 怎么得到 |
|---|---|---|
| 普通 | +0～12% | 木剑、钢刀、青钢剑、白蜡枪，铁匠铺 30～200 文 |
| 精良 | +20% | 精钢剑 / 刀 / 枪 / 飞镖，铁匠铺约 600 文 |
| **高级（约 80 分）** | **+28%** | 百炼剑 / 刀 / 枪 / 梅花镖，只有襄阳张铁匠打，2400 文 |
| **顶级（90～100 分）** | **+40% 以上** | 只从剧情、任务得到：真武剑 +40、青竹棒 +40、孔雀翎 +45 |

**规则**（`src/power.js` 的 `weaponRule`，`validate.mjs` 检查）：

```
兵器武功最狠一招的攻击值 × (1 + 高级兵器加成 28%) ≈ 同阶同势拳掌基准（偏差 ±5%）
```

- **攻击值** = 招式威力 × 效果系数（§2.1），取这一阶的上限能领悟到的最狠一招。
- **阶**：武馆一阶；门派按学的阶位分；绝学任务的奖励算镇派那一阶。
- **同势**：巧剑只和巧掌比，刚刀只和刚拳比。巧招本来就比刚招轻、带控制，不拿来硬比。
- **拳掌基准**：这一阶同势拳掌攻招里最狠的一招。没有巧招拳掌时，用刚招基准 × 0.85 当巧的基准；这一阶都没有就往下一阶找。
- 结果：拿普通兵器时兵器武功不如拳掌，拿高级兵器两边持平，只有顶级兵器能胜过拳掌约 10%～13%。
- 店里卖的兵器（对话里 `pay:` 之后 `give:`）加成不能超过 28%，校验会报。
- 参数在 `src/config.js` 的 `power.advancedBonus`、`advancedBand`、`qiaoFromGang`。

**敌人**：敌人没有兵器物品，用 `weaponBonus: 加成%` 表示"他手里那件兵器"，作用在他兵器武功的招式上，战斗力（CP）和修为都算进去。D-119 降兵器武功威力时，用它把原有敌人补回原来的强度，所以等级（以及玩家打他们拿到的实战经验）都没变。身上还有别的兵器剧情武学的敌人不加 `weaponBonus`，改为调那门武功的等级。
