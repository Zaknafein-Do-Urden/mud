# 剧情：玩家持恒山铁牌上嵩山封禅台（门槛三选一爬朝天梯）。台上五岳到齐，左冷禅主持并派。
#       玩家把调度手令和廿八铺的铜牌一起摊出来，嵩山不能再用武力压服（必胜战：赶人下台）；
#       于是改成"比剑定掌门"——岳不群当众胜出，顺手刺瞎了左冷禅。
#       左冷禅输红了眼，拿玩家出气（必败战），定闲师太与莫大先生一琴一拂挡下。
#       章末：五岳派立，掌门姓岳；令狐冲被当众逐出华山门墙。

#       玩家改变的是"嵩山没能靠人头和刀硬压过去"，以及自己从岳不群的剑里认出了什么。

定闲师太接过那块铁牌时看了你很久，什么也没问，只说了一句："师姐让你去看一眼，你就去看一眼。"
